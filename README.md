# Core Java Programming – Practical Coding & Interview Preparation

## About This Project

This repository is dedicated to learning and practicing Core Java programming through structured, topic-wise exercises and real-world coding examples.

The primary objective is to strengthen Java programming fundamentals, develop logical thinking, understand object-oriented programming and prepare for Java-based Automation Testing interviews.

All programs are developed using Java and managed through Maven in Eclipse IDE.

## Objectives

- Build strong Core Java fundamentals.
- Understand Java syntax, memory concepts and execution flow.
- Develop problem-solving and logical programming skills.
- Master Object-Oriented Programming concepts.
- Practice arrays, strings, collections and data structures.
- Understand exception handling and file operations.
- Learn Java 8 features, Lambda expressions and Stream API.
- Solve frequently asked Java interview coding problems.
- Apply Java concepts to Selenium automation testing.

## Execution Instructions

1. Clone this repository.

```bash
git clone https://github.com/YOUR_USERNAME/Core-Java-Programming.git
```

2. Import the project into Eclipse as an Existing Maven Project.

3. Configure JDK 17.

4. Navigate to the required Java package.

5. Open the Java class containing the `main()` method.

6. Right-click the class and select:

`Run As → Java Application`
